项目背景

痛点

  • 记忆系统深度耦合在主仓库 src/openhuman/memory/
  • 无法被第三方项目独立引用
  • 多端演进受阻（桌面 + 移动 + 服务端）
  • Python 和前端团队无法直接使用

目标

  • 零耦合：不依赖主仓库即可编译
  • 全能力：存储、图谱、同步、联邦学习
  • 多形态：Rust / HTTP / Python / WASM
  • 生产就绪：完整测试 + 安全审计

核心能力 ② — 多设备同步

模块职责
ChangelogLamport 逻辑时钟 + 变更日志
DeviceX25519 密钥对 + mDNS 发现
TransportLAN / Relay / Direct 三种传输
MergeLWW / Union / Idempotent CRDT
CryptoXChaCha20-Poly1305 E2E 加密

同步流程

1. 每次写入生成 ChangeEntry (Lamport TS)
2. mDNS 发现局域网对端
3. X25519 密钥交换建立会话
4. 变更加密传输
5. 对端按策略自动合并
6. 不可解决冲突存入冲突表

性能

1000 条变更写入 + 读取 < 2 秒

四种接入形态

Rust 库

cargo add openhuman-memory

适用：嵌入式集成、高性能场景

功能：全功能（存储 + 图谱 + 同步 + 联邦）

HTTP 微服务

openhuman-memory-server --port 8420

适用：多语言接入、微服务架构

功能：存储 + 图谱 + 评分（23 个 RPC 端点）

Python 绑定

maturin develop

适用：数据科学、自动化脚本、Notebook

功能：文档存储 + KV + 评分

WASM 模块

wasm-pack build --target web

适用：浏览器前端、边缘计算

功能：纯计算（评分 / 实体提取 / 相似度）
